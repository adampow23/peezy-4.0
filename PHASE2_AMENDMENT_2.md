Apply to PHASE2_EXECUTABLE_SPEC_v5, update §8.6 (each finding maps exactly once), then the next read-only pass. No worktree until zero P0/P1 and hash adoption.

1. **Schema conflicts — adopt.** Freeze one total schema per dynamic-state map: `waiting_state` includes `entered_at`; `pending_handoff` uses `action_id` (drop `target_action_id`) and includes `selected_at`. Align validators, reducers, receipts, recovery, fixtures. Mechanical.
2. **Fractional legacy fingerprints — adopt.** Bind `COMPLETE_BOOKING` and the packing complete-request fingerprints to the `TaskCanonicalV1` domain (the P1-T finite-double domain), freeze the bulk preimage/prefix/SHA, add real fractional parity/replay fixtures. Do not convert to integer units — that would change accepted request bytes for a shipped surface.
3. **Timestamp wire format — adopt.** Wire form for every timestamp in a callable request is a UTC ISO-8601 string with exactly milliseconds (the same normalization the canonicalizer already froze); the server reconstructs Firestore values and **authors every commit-time/server-timestamp field itself** — a client-supplied server-timestamp sentinel is rejected. Freeze accepted-request canonicalization and Swift/JS fixtures.
4. **Named-office display — owner decision.** A trusted, immutable `display_name` is required on the waiting transition, captured at transition time from policy or provider-directory evidence (the same provenance rule as `presentation_snapshot`: an untrusted client string is display-context, never upgraded). **When no trusted display name exists, the WAIT transition is ineligible** and the outcome lands as `USER_ACTION_TRACKED` self-follow-up with the same confirmed trigger — still owned, still trigger-bound, no opaque identifier like `mapkit:chase` ever rendered as an office name. Rationale: §A A1-5d (say what the institution said) outranks surface completeness; a WAIT card that can't truthfully name who owns the wait shouldn't claim one.
5. **Casing — adopt.** Literal `reset_dispatched`; align recovery fixtures. P1-M's lowercase decision stands everywhere.
6. **Index allowance — adopt.** Replace the flat 65,536-byte constant with worst-case charges derived from the exact task schemas and the frozen index configuration (arrays/maps charged per their actual indexed entries; add explicit field exemptions to `firestore.indexes.json` where derivation shows they're needed), validated by an independent boundary oracle: the emulator worst-case fixture must fail over-budget and pass at-budget. The 8 MiB ceiling with 20% headroom stands.
7. **Scheduler prepass — adopt.** The PEEZY_STATE-required event-envelope pass (validation, conflict quarantine, high-water advancement) is frozen as an ordered prepass before all seven scans, with its bounds, quarantine behavior, and regression tests carried into the rewrite. The scheduler contract explicitly names it as phase 0 of every run.
8. **Worktree `File.txt` — adopt verbatim.** Guarded worktree-only empty `File.txt` (SHA-256 `e3b0c442…b855`), created after worktree creation and before any build, guaranteed cleanup, patch-exclusion proof, and verification that main's protected untracked `File.txt` hash is unchanged at every checkpoint.
